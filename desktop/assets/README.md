# Desktop pet artwork

- `packs/whale-girl/` — **primary artwork**, downloaded from the MIT-licensed community
  project [`vlln/whale-girl`](https://github.com/vlln/whale-girl)
  (`lib/assets/characters/whale-girl`, credit: ZipZipPipe). 15 states, 1–3
  frames each at 256×256 per cell, timing in `manifest.json` (fps + playback).
  MIT License, © 2026 Sam Gao (vlln).
- `packs/deep-chan/` — high-resolution 8×9 atlas from
  [`zhu1090093659/dsh-pet`](https://github.com/zhu1090093659/dsh-pet), manifest
  says `Personal-Use-Only`; kept locally as an alternative, not redistributed.
- `frame0.png` / `frame1.png`（根目录） — 2-frame low-res fallback sliced from a
  screenshot supplied by the user.
